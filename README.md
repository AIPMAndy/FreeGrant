## 01 / 先看你有几个身份

例：上海户籍、生活在北京、有上海公司和个体工商户执照（个体户注册地待确认）、懂AI且具备开源与商业交付能力。身份是筛选入口，不是领钱凭证。

| 身份 | 第一个动作 | 决策约束 |
|---|---|---|
| 个人/家庭 | 随申办、参保地医保、个人所得税APP | 真实户籍、监护、参保与历史领款 |
| 上海公司 | 一网通办企业账号、注册区就业中心 | 注册地、实际经营、人员、信用、财务 |
| 个体户 | 单独核对注册地、经营所得、社保 | 不因多执照重复领取同一人政策 |
| AI技术创业者 | 查询正规技能评价、OPC园区、赛事 | 真实技术、产品、市场证据与属地条件 |
| 北京居住者 | 北京人社、昌平区政府赛事/扶持公告 | 居住不是注册、社保或人才资格 |

## 02 / 30分钟摸清资格

复制 `templates/profile.local.example.json` 到**自己的私有本地目录**，填完以下事实：公司和个体户注册区、成立日、负责人、实际经营地、社保地和真实用工月份；户籍地、真实就业状态、证书及既往补贴；家庭资格、既往申领；企业收入、研发投入、知识产权、开源及客户证明。不确定就填 null。身份证号、银行卡号、验证码不要输入公开网站、GitHub或公共AI对话。

## 03 / 先现金、后奖金、再节税

P0 是优先检查或采取行动，不等于符合资格。P1 需预审、准备或等待批次；P2 为长期培育。条件限定表示当前案例不应默认享受。现金·普惠/待遇与现金·培训、现金·费用返还、竞争性奖金及专项经费分别计账。节税、券和采购订单独立列账；不将所有最高额度相加。

**净收益 = 实际到账 + 实际节税 + 可兑现且实际用掉的成本节约 − 新增费用 − 时间机会成本 − 迁移/履约成本 − 适用税费。** 申请前可以使用自己的概率假设做敏感性分析，未获官方核准的金额不能当作确定收益。

## 04 / 7天行动计划（匿名示例）

- 第1天：随申办查询育儿及历史待遇；分别登录公司/个体户政务账户检查待兑现资金。没有符合条件的孩子就跳过家庭项目。
- 第2天：打上海12333，询问1800元创业培训和AI技能评价；确认异地工作和报考身份，先不付费。
- 第3天：查公司和个体户设立日期、社保及历史创业补贴，判断初创社保补贴的唯一主体；问注册地街道。
- 第4天：选1—3个真正可用的AI产品，整理技术架构、真实活跃、贡献和客户价值；用同一套材料问徐汇与临港预审。
- 第5天：核查北京注册地及资格；没有北京主体时，优先个人技术竞赛、公开活动而非申请属地企业补贴。
- 第6天：会计核对公司所得税、个体经营所得减半及2026增值税起征点；依法更正多缴，不拆单。
- 第7天：把每条机会登记为未核验/条件不足/待窗口/已提交/已通过/已到账，复核回执；给出未来30、90天计划。

## 05 / 多身份组合：真实业务是边界

- 公司与个体户分别拥有真实独立业务时，按合同、实际交付、收款、开票和成本归属核算；不是为了不同税率临时更改主体。公司利润及股东分红、经营所得税负、社保、责任风险都要纳入测算。
- 上海初创社保补贴的同一负责人只享受一次；个体经营所得多处取得须汇总。个人培训次数和同工种等级限制不会因执照增加而翻倍。
- 上海户籍、北京居住、上海公司是三件不同的事。向经办机构如实说明实际经营、工作地点、人员和社保。若某奖励要求实际在园区运营，就算迁址能获批，也必须真正履行义务。
- 获得税费减免、育儿待遇或符合条件的创业补贴可以是不同制度，但任何具体政策叠加都要核对同一人/主体/项目/费用/发票/周期、互斥条款及资金用途。尤其临港、徐汇同类资金原则上从高不重复。
- 不预付高额中介费，不假用工、不挂靠、不买证、不伪造开源指标、不虚构研发或隐匿收入。专项资金按要求使用、验收、纳税、留档；接受核查和追缴风险。

### F01｜育儿补贴

**上海 / 全国 · 家庭 · 现金·普惠 · P0**

**标准：**3,600元/孩/年；按规定月数、年度核定

**窗口：**2026年度已开通；出生当年或次年首次申请，续领按年度办理。

**资格：**
- 孩子在上海登记户籍且不满3岁；父母一方或其他监护人履行抚养义务；未重复申领。

**怎么办：**
1. 微信/支付宝搜“育儿补贴”或随申办育儿补贴专区。
2. 先查2026年度状态；首次申请按提示提交，已领者核对后续领。
3. 关注随申办免申即享推送；核对审核、收款人及实际到账。
4. 2022—2024年出生且错过首次申请者，查看延长通道，2026-12-31截止。

**材料：**出生医学证明、户籍信息、监护人身份、本人收款信息；按系统要求提供。

**避坑：**父母双方不得重复提交；外地生活不等同外地户籍；不得向所谓代办人提供验证码。

**入口：**[2026育儿补贴操作指南](https://www.shanghai.gov.cn/nw17239/20260107/0d4596eea88646b4bdc09f0dca35ac48.html)

**依据：**[上海育儿补贴实施方案](https://www.shanghai.gov.cn/gwk/search/content/4033fa8cecda4cf28fcf39b74ff5d788) · [2026育儿补贴操作指南](https://www.shanghai.gov.cn/nw17239/20260107/0d4596eea88646b4bdc09f0dca35ac48.html) · [育儿补贴一件事及免申即享](https://www.shanghai.gov.cn/gwk/search/content/d36077e07001445295b4617756bf55c8) · [2022—2024年出生儿童首次申请延期通知](https://www.shanghai.gov.cn/xbhygq/20260722/4ae76ba3de9e4586970c20154c1cba59.html)（核验：2026-11-27）


### F02｜生育生活津贴及待遇漏领核查

**上海 / 参保地 · 家庭 · 现金·待遇 · P0**

**标准：**按生育时适用政策、参保和计发基数核定

**窗口：**核查历史申领；不假设补领一定可行。

**资格：**
- 实际生育或符合规定的情形；满足当时的生育保险条件。

**怎么办：**
1. 登录随申办搜索“生育保险待遇申领”，或查生育时参保地医保平台。
2. 下载生育月份前后的参保记录、津贴历史与医疗结算记录。
3. 若异地生育或漏领，拨打参保地12393确认申领时限和材料，再按答复提交。

**材料：**参保记录、医疗机构材料、已领取记录、收款账户。

**避坑：**2026年修订规则不能直接倒推早期生育；以当时政策为准，不同地区不重复领。

**入口：**[上海生育保险政策（2026年修订，按生育时点核对）](https://www.shanghai.gov.cn/gwk/search/content/79e981546eaf4727ae47502f4de955b8)

**依据：**[上海生育保险政策（2026年修订，按生育时点核对）](https://www.shanghai.gov.cn/gwk/search/content/79e981546eaf4727ae47502f4de955b8)（核验：2026-11-27）


### P01｜创业初创期培训补贴

**上海 · 个人 / 创业者 · 现金·培训 · P0**

**标准：**1,800元/次；合计最多3次（5,400元上限）

**窗口：**2026-01-01至2030-12-31；证书颁发后12个月内申请。

**资格：**
- 本市创业3年内创业组织负责人、法定代表人或持股合伙人。
- 参加获认可的不同创业初创期培训项目并取得合格证书。

**怎么办：**
1. 拨打12333，问注册区就业促进中心：在册创业初创期培训项目、机构名单、线上/线下、收费和报班时间。
2. 只报名主管部门确认的项目；核对人在北京能否参加及实操考核要求。
3. 完成培训及考核；取证后在一网通办搜索“创业培训补贴”或到区就业促进中心申领。
4. 核对公示与社保卡银行账户入账。

**材料：**营业执照或持股证明、身份信息、培训合格证书、社保卡金融账户；具体以办事指南为准。

**避坑：**同一培训项目仅一次；3次为个人总上限，不因两张执照翻倍；先问费用，净收益可能不为正。

**入口：**[上海一网通办](https://zwdt.sh.gov.cn/)

**依据：**[沪人社规〔2025〕30号 创业培训](https://www.shanghai.gov.cn/gwk/search/content/t0035_1438023)（核验：2026-11-27）


### P02｜AI职业技能等级证书补贴

**上海 · 个人 / 技术人才 · 现金·培训 · P0**

**标准：**A类标准：初级1950、中级2600、高级3250、技师3900、高级技师4550元；按身份比例核算

**窗口：**2026目录3月1日起实施；一般证书颁发后12个月内申领。

**资格：**
- AI训练师等在补贴目录内；由认可评价机构发证。
- 沪籍不代表当然符合条件：在职、灵活就业、其他身份按真实状态审核；在职通常取证后在沪就业6个月按80%。

**怎么办：**
1. 打开2026目录，优先查AI训练师、数字化解决方案设计师、计算机程序设计员。

**材料：**合法技能证书、身份、就业/参保信息、必要的岗位材料和收款账户。

**避坑：**灵活就业等部分身份可按100%，在职通常80%；同工种同等级不能重复，更低等级不能回头领；不得虚构失业。

### E01｜初创期创业组织社保补贴

**上海 · 公司 / 个体户 · 现金·费用返还 · P1**

**标准：**单位养老、医疗、失业保险按当月缴费基数下限计算金额的50%；最多8人

**窗口：**注册36个月以内；吸纳就业满6个月后核对申报周期。

**资格：**
- 本市注册的小微企业、个体工商户等；负责人符合户籍或证件条件。
- 吸纳符合规定的本市劳动者就业满6个月，依法参保，登记、缴费与申领主体一致。

**怎么办：**
1. 用一网通办或社保系统查真实用工和每人参保月份。
2. 给注册地址街道社区事务受理服务中心打电话，核对负责人本人能否计入、员工口径、异地办公影响、月份追补和两主体历史。
3. 满足条件后申请“初创期创业组织社会保险补贴”，按要求提交并跟踪核定。

**材料：**营业执照、负责人身份、劳动合同、社保与就业登记、补贴申请表及单位账户。

**避坑：**同一负责人创办多个组织只能享受一次，不能公司与个体户各领一次；不为返还社保而虚构雇员。

**入口：**[上海一网通办](https://zwdt.sh.gov.cn/)

**依据：**[沪人社规〔2023〕1号 创业扶持](https://www.shanghai.gov.cn/202308bmgfxwj/20230504/ee335ef455a04111ab3684cc1e991220.html) · [2026初创期创业组织社保补贴经办提示](https://www.shanghai.gov.cn/nw17239/20260604/6a2177a08c0f47d094dfc6061efad17a.html)（核验：2026-11-27）


### E02｜首次创业一次性补贴

**上海 · 公司 / 个体户 · 现金·普惠 · 条件限定**

**标准：**8,000元一次性

**窗口：**首次创业满一年且符合身份等要求后查办理期限。

**资格：**
- 首次本市创办；注册时为沪籍毕业两年内高校毕业生或本市就业困难人员；至少一人依法缴纳城镇职工社保满6个月。

**怎么办：**

2. 符合者进入首次创业补贴办事指南，下载申请表，向注册区经办机构提交。

**材料：**营业执照、负责人身份、社保卡银行账户、申请表及系统需要的证明。

**避坑：**沪籍或新公司本身不足以满足条件；第二张执照不重置首次创业。

**入口：**[一网通办首次创业一次性补贴办事指南](https://www.shanghai.gov.cn/affairs_affairs/0595cbd5c4974649b9cfb03b3d217daf.html)

### E03｜创业团队孵化场地费补贴

**上海 · 创业团队 · 现金·费用返还 · 条件限定**

**标准：**实际符合费用；最高1万元

**窗口：**入孵到注册期间、最长6个月；按经办规则办理。

**资格：**
- 先进入市级创业孵化示范基地，孵化期内成功注册符合条件创业组织。

1. 分别确认公司与个体户纳税人类型和真实业务合同。
2. 对照2026新增值税法及公告核算含税/不含税收入、专票与免税情形。
3. 接近起征点前和会计核对，按真实纳税义务申报，保留凭证。

**材料：**销售明细、发票、合同、申报表。

**避坑：**2026法制衔接须以现行起征点规则为准，不能照搬旧版“含本数”；严禁拆单、隐瞒或虚假延迟收入。

**入口：**[国家税务总局](https://www.chinatax.gov.cn/)

### T04｜家庭专项附加扣除与多缴退税

**全国 · 家庭 / 个人 · 节税·非补贴 · P0**

**标准：**照护/教育每孩2000元/月；赡养老人按法定标准；实际减税按税额

**窗口：**现行规则；按年度确认与综合所得汇算。

**资格：**
- 有对应真实家庭支出及扣除资格；符合个人所得税规则。

**怎么办：**
1. 打开个人所得税APP，核对2026专项附加扣除：婴幼儿照护、子女教育、赡养老人、住房等真实项目。
2. 夫妻测算一方100%或双方50%的照护扣除，不重复；年度内不得随意变更分配。
3. 在汇算期核对已预扣税与最终税额，若存在多缴依法申请退税。

**材料：**真实关系及扣除证明，按政策留存备查。

**避坑：**扣除额不是退税额；没有多缴税不会凭空产生退税；经营所得与综合所得扣除规则须核对。

## 07 / 开源技术项目怎么变成申报资产

建立每个项目的证据包：公开仓库URL、开源许可证及第三方依赖、实际可用的Release、3分钟产品演示、问题与技术创新、架构图、安装/复现实验、真实性能指标与对照、真实下载/活跃/客户反馈、合同验收（仅私下提供脱敏版）、知识产权归属、企业与个人之间的真实授权、研发辅助账、过去6个月收入及支出（仅私下）。公开Star只作辅助，不购买流量、不编造用户、不把教程仓库自动认定为技术研发。

优先准备一个能运行且能赚钱的核心产品，其次准备AI技能包与开发工具。问主管部门“认定标准是什么”“以前的成果算不算”“是否需要先备案”“奖励是无条件奖金还是限定用途资金”“同项目能否叠加”“什么时候拨款”“没有获批会有什么成本”。得到书面答复后再实施。

## 08 / 30天与90天迭代

**30天：**完成个人/家庭资格盘点；完成两主体税务和社保核查；取得正式培训机构及项目清单；完成1页公司介绍和项目证据；对徐汇、临港、当前注册区形成三份预审记录。若无开放窗口，就把下一次官方公告的订阅和复查日期列入台账，不盲目报旧项目。

**90天：**建立研发辅助账、发布可复现的技术成果和真实用户证据；按需参加符合条件的培训/赛事；在满足社保等资格后申请；如考虑园区入驻，单独比较6—12个月的真实运营成本与获批概率。不要为达到研发50万元或API5万元的门槛而无业务需求地烧钱。
